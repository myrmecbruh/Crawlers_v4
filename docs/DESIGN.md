# Design overview

## Vision
- [gospel] A very low-system-impact, semi-idle dungeon crawler / colony survival / life sim.
- [gospel] Mobile and desktop, written from the ground up.
- [gospel] Isometric pixel art.
- [gospel] Grimdark low sci-fantasy.
- [gospel] Endless sandbox: survive as long as you can; raids and depth escalate; the story is the goal.

## Pillars
- [gospel] Board-game feel and small numbers.
- [gospel] Every resource token is visible in the world.
- [gospel] Dice rolls, shown.
- [gospel] Occasional cards.
- [gospel] Engine building.
- [gospel] Exploration.
- [gospel] Six traits, like D&D attributes.
- [gospel] Fail-forward skilling.
- [gospel] Six worn equipment slots, all visible on the character in game.
- [gospel] Material tags on every item, object and resource (type of metal, stone, wood, fiber, etc.).
- [slop] No hidden numbers: if a rule uses a value, the player can see it as tokens, pips or dice.

## Inspirations
- [gospel] Dwarf Fortress, Rise to Ruins, RimWorld, Desynced, Kenshi, Colony Survival, Valheim, KeeperRL, Stranded: Alien Dawn, Dungeon Settlers, Moonlighter.

## Setting
- [gospel] The possible premises are all true or possible, chosen like RimWorld's starting conditions: ruins of a fallen machine age (survivors in the husk of a dead high-tech civilisation, its failing machinery passing for magic); crashed or stranded colonists in an old, hostile, haunted world; an endless built underworld megastructure.
- [gospel] All three scenarios are available from the start.
- [slop] A new game picks a starting scenario. The scenario sets the starting colonists, tokens, plot and first event cards. It does not change the rules.

## Player role
- [gospel] The colony is controlled indirectly: it runs itself.
- [gospel] The player assembles parties and sends them into the dungeon.
- [gospel] Party orders are a goal only (for example: bring ore, map the zone, kill the nest). The party decides everything else.
- [slop] Colony control is by job priorities per colonist, build orders and stockpile zones.

## Core loop
- [slop] 1. The colony works: gather, haul, craft, eat, sleep, keep warm.
- [slop] 2. The player builds stations and devices to turn tokens into better tokens.
- [slop] 3. Local resources run short, so the player sends a party through a border with a goal.
- [slop] 4. The party crawls, rolls dice, gets hurt, learns from failure, and hauls back tokens and cards.
- [slop] 5. Cards join the settlement deck; the daily draw brings boons and banes.
- [slop] 6. Breaching borders grows the map, the threat, and later the raids.

## Scale
- [gospel] 3 to 6 colonists.
- [gospel] New colonists arrive by cards (wanderer, captive, survivor) and by rescue: found downed or caged in the dungeon and carried home like any token.
- [gospel] Traits run 1 to 3. Skills run 0 to 3. Dice pools are 1 to 6 dice.
