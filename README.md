# Crawlers v4

A very low-system-impact, semi-idle dungeon crawler / colony survival / life sim for mobile and desktop, written from the ground up.

Design phase: no code yet. Start with `docs/`.

| Doc | Covers |
|---|---|
| `docs/DESIGN.md` | Vision, pillars, setting, core loop |
| `docs/RULES.md` | Traits, skills, dice, needs, wounds, equipment, materials |
| `docs/WORLD.md` | Voxels, generation, borders, expeditions, raids |
| `docs/SETTLEMENT.md` | Tokens, stations, devices, cards |
| `docs/TECH.md` | Stack, ticks, performance, art specs, UI, saves |
| `docs/CONTENT.md` | Draft lists: materials, stations, creatures, goals, cards, scenarios |
| `docs/ROADMAP.md` | Build order |
| `docs/OPEN-QUESTIONS.md` | What is still undecided |

Every statement is tagged **[gospel]** (ordered by the owner) or **[slop]** (proposed by the assistant, free to overrule).
